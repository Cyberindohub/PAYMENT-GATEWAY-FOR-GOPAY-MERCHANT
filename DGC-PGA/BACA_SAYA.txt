TROUBLESHOOTING
------------------------------------------------------------------------
  - uvicorn not found        : Python 3.11/venv belum aktif (pakai Python Project Manager)
  - Mongo Authentication fail : ganti authSource=gomerch -> authSource=admin di MONGO_URL;
                                pastikan '#' pada password ditulis %23
  - Frontend blank / API error: paket ini sudah di-build untuk https://v1.x-api.asia.
                                Jika domain berbeda, frontend harus di-build ulang.
  - /api 404                  : cek blok location /api/ di Nginx & backend jalan di 8001
